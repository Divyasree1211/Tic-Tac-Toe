# Tic-Tac-Toe
A simple project to practice Html ,CSS and Java Script [to practice Event Handling]

Instructions to play:
No of grids: 9
No of players: 2
player O,player X
Alternate chances to play
To play Tic-Tac-Toe, two players take turns marking spaces in a 3x3 grid with 'X' or 'O',
aiming to get three of their symbols in a row (horizontally, vertically, or diagonally) before the opponent does; 
if all nine squares are filled without a winner, it's a tie.
